# Agentic Web Development

A model-independent, Python-based agent orchestration system.

## Principles
- Eight workflow stages aligned with the project guide.
- Six human approval gates: G1-G6.
- Persistent artifacts and resumable workflow state.
- Explicit agent roles, skills, and permissions.
- No model provider is required for the initial orchestration tests.

## Initial milestone
Run the workflow without an LLM, then execute the Requirements Analyst
and save its approved-candidate specification under specs/001/.
