# Procedure
1. Read the feature request and relevant existing specifications.
2. Write user stories.
3. Give each requirement a unique ID and priority.
4. Use unambiguous, testable requirement statements.
5. Add Given/When/Then acceptance criteria for required behaviour.
6. Include validation, failure, boundary, privacy, and security cases.
7. List assumptions and unresolved questions.
8. Submit the specification for G1 human approval.
